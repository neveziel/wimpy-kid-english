# 📘 윔피키드 영어 한 문장 — Diary of a Wimpy Kid 1권

『Diary of a Wimpy Kid』 1권을 공부할 때 쓰는 아이폰용 학습 웹앱입니다.
원서 전체가 아니라, 공개 학습 노트에서 고른 **핵심 문장 159개**를 16개 파트로 나눠 담았습니다.

**라이브:** https://neveziel.github.io/wimpy-kid-english/

## 구성

- **159문장 / 어휘·구동사 표현 400여 개** — ① 영어 문장 ② 자연스러운 한국어 해석 ③ 뉘앙스 해설
- **원어민 음성 159개** — `edge-tts` `en-US-AndrewNeural` MP3 (`audio/001.mp3`~`audio/159.mp3`)
- **파트 필터 · 검색** — 영어·한국어·표현 어디로든 검색
- **🇰🇷 한글 해석 ON/OFF** — 전체 토글 + 해석 OFF 상태에서 카드별 개별 보기
- **속도 0.8x / 1.0x / 1.2x**, 문장별 듣기, **전체·파트 연속 듣기**(흘려듣기)
- **학습 완료 체크** — `localStorage`에 저장, 상단 진행률 표시

## 아이폰에 설치

Safari로 주소를 열고 **공유 → 홈 화면에 추가**. 전체 화면 앱처럼 열립니다.

## 저작권

문장 저작권은 Jeff Kinney / Amulet Books에 있습니다. 개인 학습 목적의 짧은 발췌와 해설이며,
원서를 대신하지 않습니다. 오디오는 공개 TTS로 새로 생성한 음성입니다.
